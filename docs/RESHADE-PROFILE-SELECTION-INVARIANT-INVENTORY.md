# ReShade profile selection system invariant inventory

Status: current to the RC8 direct-selector and closed-gallery precedence source edits plus the uncommitted cloud-review repair pass (selector guard restore and reopened-preview ownership). An earlier independent closed-gallery review found no findings; the later independent cloud source review completed with findings, which that repair pass addresses in source and tests. The repair pass has not been run under PowerShell, and any aggregate gate recorded earlier in the reconciliation report predates it, so fresh applicable Windows gates are required. This inventory does not assert a result for any final aggregate gate. The late-inventory timing deviation remains open.

Process note: the component meets the REQUIRED system-invariant trigger because deployment stages and atomically promotes multiple dependent files, configuration, and ownership state. This inventory was identified after implementation had begun. It records the current design guarantees, but does not retroactively satisfy the required before-implementation timing; independent review must assess that deviation before the slice is called Review Ready.

## Boundary

This inventory covers curated profile selection, live acquisition of approved shader files, shared include closure, preview rendering, deployment/configuration, and TPM ownership state. It does not claim shader compilation, GPU behavior, or owner-runtime validation. The separate ReShade installer-package extraction path remains in `RESHADE-DGVOODOO2-AUTODOWNLOAD-INVARIANT-INVENTORY.md`.
