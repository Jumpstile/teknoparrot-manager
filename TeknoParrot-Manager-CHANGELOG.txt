  Newest version first. RC9.3 is the latest published version. RC9.2 is the
  previous published version. RC9.1 came before it. RC8 was a tester build and

  v1.0 RC9.4 (changes since RC9.3)
  ----------------------------------------------------------------

  - LaunchBox playlists now sit under TeknoParrot; same-name ones stay as is. The LaunchBox folder is remembered.
  - The country question: type L and a number (example: L1) to see its games.
  - The ReShade result now says the Home key opens the ReShade effects menu. Guide wording fixed. ReShade picks its hook from the game's real imports; ReShade, dgVoodoo2, GPU Fix and bezel results now say only what happened.
  - Menu 4 is now named Controls. AutoSync, Register and menu 4 set up controls
    only with your controller layout; copying from example games is removed.
  - After the picture download, TeknoParrot Manager names the games still
    without a picture and lets you pick your own PNG for each one.
  - Choose your controller layout now has "My learned arcade controls" for an
    arcade encoder in keyboard mode. It changes nothing and needs no mode switch.
  - Controls fit your pad (volume on L3/R3, any slot); choice 5 sets any by hand. A clash skips one. TPM also looks for Wii remotes, guitars, drums and dance pads, and you can say what any device is.
  - First-run setup now names its two folder questions "TeknoParrot folder"
    and "Staging folder for game files", with the same type-a-path and
    B-to-browse choices, and never offers a folder without TeknoParrotUi.exe.
  - The main menu shows Game Requirements in its own color. In a small window
    each option shows in its section color, with one line naming the colors.
  - AutoSync no longer stops when you reach the LaunchBox step.
  - After Health Check repairs game paths, the result now says how many games
    were repaired and how many still need you, and what to do next.
  - Game Path Repair now uses the folder names and file name of a game's old
    saved path to find it after you move your library. It saves a game only
    when one file clearly fits, offers to let you pick the file for the rest,
    and says "Partly done" instead of FAILED when some games need your help.
  - You can rebuild several games from their ZIP files in one go.
  - Games that TeknoParrot adds later now register and show up in your Game
    Notes file without a new TeknoParrot Manager version. Game Notes also
    shows TeknoParrot's own platform, release year and known issues for
    games with no notes of their own, marked as coming from TeknoParrot.
  - When TeknoParrot has been updated, TeknoParrot Manager now tells you at
    start how many games are new or changed, and if a profile cannot be read.
  - Game rules (game notes and graphics-card warnings) can now be updated
    without a new TeknoParrot Manager release. The update is a small signed
    data file. It never changes your game or TeknoParrot files, and you can
    turn it off with the GameRulesUpdate setting in
    TeknoParrot-Manager.config.json. You are told once.
  - A recovery file already gone, in a folder with square brackets in its
    name, is now correctly seen as missing on Windows PowerShell 5.1.
  - The ReShade preview window now stays inside the screen, and the ReShade
    list names all four groups again.
  - ReShade setup: pressing B at the first one-by-one question goes back to
    the previous menu instead of canceling. The install line counts only the
    games really being changed. The profile question says nothing changes
    until you choose games; the apply question says it changes game folders.
  - ReShade setup: when a game already uses TeknoParrot's CRT look, the
    notice says that look stays on, ReShade adds another effect, and names
    the game. A game whose 32-bit or 64-bit type cannot be read is left
    unchanged, with a plain note that it is not damaged.
  - The ReShade guides now say 32-bit and 64-bit games both work, and list
    ReShade32.dll next to ReShade64.dll.
  - ReShade setup for many games now ends with a short summary and groups
    skipped games by reason. It no longer warns about a failure when every
    game that could be set up was set up. Press D for the game lists.
  - dgVoodoo2 setup: the scan line shows how many games were checked out of
    the total, and explains that kept DLL files are not checked or replaced
    and that dgVoodoo.conf comes from your dgVoodoo2 folder.
  - dgVoodoo2 setup: one summary now names how many games were checked,
    need it, were set up, were already set up or were skipped, with [D]
    Details for each game, also when nothing needed changing.
  - In the game list, a game's second profile uses the second executable
    named in the list when the profile names no game file.
  - Forgot your PostgreSQL password: a short explanation of why it cannot be
    reset automatically, then 8 numbered steps to reset it yourself, ending
    with turning the safety check back on. The Action Required list and the
    validation report point to those steps and save them. There is also a
    new User Guide appendix and matching Troubleshooting and Postgres Setup
    wiki sections.
  - TeknoParrot Manager no longer looks up a game list online. It reads the
    profiles in your own TeknoParrot GameProfiles folder.
  - The license file and a few notes now use American English.
  - Required game patches: the APM3 patches for several ALLS games (such as
    Otoshu DX, Dead or Alive 6 and Rolling Gunner) now also accept the
    game's own ZIP. When a patch ZIP is not found, the screen names the
    exact files that would work and says TeknoParrot Manager does not
    download them.
  - A settings file that cannot be read is now left as it is and not saved
    over. TeknoParrot Manager tells you how to fix it or rename it.
  - Undo for a bezel now puts your own saved bezel back even when the copy
    TeknoParrot Manager made was already deleted. The one-time game rules
    notice is shown only when the update can really run, and a game rules
    update that fails halfway keeps the rules you had.
  - The guides no longer tell you to delete a dgVoodoo.conf you may have
    edited without copying it first. They also say that the PostgreSQL
    "start any game" line appears only when every game is ready, and that
    B does not cancel at the first ReShade menu.
  - The guides now say a Preview still reads your files and writes the log,
    that recovery copies are not private on FAT drives, and that LaunchBox
    must be closed before a restore.

  - Several screens now say only what is true: Undo for a rebuilt game, the
    LaunchBox preview and results, the PostgreSQL results, the force
    feedback and BepInEx results, and the library health check, which no
    longer says everything is fine when a check could not run.
  - Graphics-card warnings now appear for AMD and Intel players. They were
    missing, and a red error line showed instead.
  - Learn my arcade buttons now keeps the keys you saved before and asks only
    for the controls that have none.
  - ReShade setup: typing a look's number now shows a short line, not the
    whole list, and U goes on to choosing games (no second question).
  - The saved game files offer now says "TeknoS11 arcade games" and lists all
    its boards equally (System 10, System 11, System 12, Sony ZN, Konami 573, Taito G-NET).
  - AutoSync no longer skips a game just because another edition of the
    same title (for example an "APM3 Edition") is in the same run. When a
    ZIP cannot be unpacked, the screen now names the game, and the log says
    which file did not match.
  - The TeknoParrot Manager log no longer grows without limit. At start,
    a log over 5 MB is kept as one "previous" log and a new log begins.
    The support package includes both.
  - Screens, lists and reports now show each game's full title (for example
    "Tekken 2"), not its profile code, in Controls too. Code stays in log.
  v1.0 RC9.3 (changes since RC9.2)
  ----------------------------------------------------------------

  - TeknoParrot Manager is made for beginners and is also useful if you
    already know TeknoParrot: repeatable bulk steps, previews, backups
    before changes, and a read-only validation report. Details stay one
    step away (see docs\ADVANCED-USERS.md).
  - The guides now explain why a game can work from TeknoParrot but not
    from RetroBat, and who does what. They also give the right bezel undo
    path (6, B, U).
  - AutoSync no longer takes a game's ZIP as already unpacked when the folder
    it found belongs to a different game with a similar name. Each ZIP gets
    its own folder, and a saved record that names another game's folder is
    ignored. Repair says when it cannot tell game paths apart.
  - Unpacking a game shows progress by size, and Ctrl+C shows "canceled"
    instead of "failed". If the games folder you chose cannot be used, Q goes
    back to the menu, and a closed browse window asks again.
  - The PostgreSQL offer after adding games says how many other games still
    need it. In a preview it names them without asking for anything secret.
    Setup screens now name Golden Tee Live 2020. If PostgreSQL cannot be put
    back after a stopped setup, the screen says what happened to your
    databases and that the service is the open problem.
  - The Capcom CPS3 first-boot files step lists your CPS3 games and stops
    without changes while a CPS3 game is running.
  - Before you confirm Copy Controls, each control type shows which example
    games it is copied from, and games with no example are listed as still
    needing controls.
  - BepInEx setup shows your list before installing: new installs and
    updates apart, each with a reason, and you can take games off. Library
    health check counts BepInEx games as installed, missing, not supported
    or not checked.

  v1.0 RC9 (changes since RC8.4)
  ----------------------------------------------------------------

  Controls
  - Controller layout (Propagate Controls, menu 3): choose your layout once
    (Xbox, PlayStation, Nintendo or arcade stick), change any button, then set
    up one game, all your games, or game by game. You see a preview and approve
    once. A saved copy is made first, every changed game is read back, a game
    that does not read back correctly is put back exactly, and one step undoes
    the whole run. A game is left alone, with a plain reason, when its saved
    settings are for another version, a control is missing, or an Xbox button
    is already used. Triggers and analog sticks are never set. Test and Service
    stay empty unless you give them a button.
  - Controls check (Propagate Controls choice 4, and a Controls line in Library
    health check) sorts every registered game into every control set up, some,
    none, or "cannot tell", and names the missing controls. For most games the
    list comes from TeknoParrot's own game file and says that no person has
    checked it. It changes nothing and never says a game is ready.
  - The Device Survey saves your answers in TPM's own settings
    folder and asks one question next time: "Keep these answers?" It asks
    again only if a controller turns up that you said you do not have. A
    damaged answers file is set aside, never overwritten.
  - "My controls" (choice 5) learns your arcade buttons: press each control and
    TPM remembers the key it sends. If LEDBlinky is installed it offers its key
    list first. Before it learns, it checks for a stuck button (2 seconds,
    hands off) and tells you if a press also sends another key or a button
    stays down after 3 seconds. It offers the standard keys that MAME and
    Ultimarc I-PAC boards use only after you say yes and two buttons you press
    send those keys. Nothing in your game files changes.
  - TPM tells you when you changed your arcade encoder. It keeps a private
    one-way code for each Ultimarc-type encoder (maker and model numbers are
    never saved, logged or shared) and says whether it is the same encoder, one
    was added or removed, or it could not check. It is a hint only and never
    changes a saved key or answer. A different USB port is not a change.
  - You can show or print the controls of one game, and your cabinet's
    controls, as a page with pictures: each control, your key, and whether
    the game has it set up. It suggests your key only for coin, start,
    numbered buttons and plain directions, and says "I'm not sure" for the
    rest. If your own LEDBlinky file gives a control a color, it shows.
  - The page for one game now says if your cabinet has enough players
    and buttons, and which device the game needs (trackball, spinner,
    wheel and pedals, light gun) that you said you do not have, with
    what can stand in (an Xbox controller to steer, a trackball or the
    Xbox stick to aim). It says "not known" when you never told
    TPM. It only compares and changes nothing.
  - Learning buttons asks if your cabinet has an Exit, Pause or Menu
    button (Esc counts as a key for these). My controls offers "6 = Undo
    my last save" when an older copy of your answers exists: it shows
    what comes back, asks once, and keeps your newest answers as a copy.
  - You can tell TPM that a game played well. It keeps that with the date and
    the game's revision, and calls the controls Verified until they or the
    settings change. Starting a game never makes it Verified. Wheel, gun and
    other analog games need you to say the calibration is done first. A
    first-run Test or Service menu step can be marked as still to do.
  - When Propagate Controls skips games because no game of their type has
    your controls yet, it names one game of each type to set up first in
    TeknoParrotUI and says that choosing a device does not set up a game.
    The registration screen ends with "Registration run finished", which
    does not mean every game's controls are set up.
  - The Propagate Controls screen no longer says "No game is registered
    or extracted.", which read as if nothing was registered on your PC. It
    now says that the screen never registers or unpacks games.
  - A read-only check of an outside controller list (for example RetroBat's
    teknoparrot.yml), run from the command line with -MappingEvidenceFile and
    -ValidationRoot. It prints plain counts, trusts nothing and changes no
    profile. It holds back a game, and says why, when the list names it twice,
    sets a control twice or one the game does not have, uses an unknown button
    name, or puts two game actions on one button.

  Games and registration
  - Every game in the Eggman list was run through the real registration on a
    fake collection (1,596 games) and the gaps are fixed. A game gets the
    profile the list names for it, not the one with the most alike name (The
    King of Fighters XII was registered as XIV). A second version of a game is
    registered, or reported as a duplicate when TeknoParrot has one profile for
    both. A second profile the list names is registered when TeknoParrot
    retired the first (the ElfLdr2 profile next to each Lindbergh game). Files
    ending in .exec or .chd and names with a hyphen (R-Tuned) are recognized. A
    folder for a game TeknoParrot has no profile for (Sega Rally 3 track mods)
    is listed as "not in TeknoParrot", not as a failed profile.
  - A game set is never registered just because its parent ZIP is in the
    folder, except when the Eggman list names the parent ZIP (17 games,
    such as Dance Dance Revolution 2nd Mix Link). TeknoS11 arcade games need
    both ZIPs in one folder. The disc image (CHD) is chosen when there is
    only one, never guessed when there are several. If you have your own
    saved files set, TPM can copy the files for your games. It never
    replaces a file that is there and says which games the set lacks.
  - Startup files for Chihiro, PlayStation 3 and the other systems that
    need them now work like the CPS3 step. If TPM cannot find
    them, it asks once for your Supplementary folder and remembers it.
    One Y installs everything. The result names what was installed,
    already matching, missing (by file name) or invalid, and the folders
    searched.
  - Library health check names game types it does not know, games
    TeknoParrot has not released yet, emulators missing from your
    TeknoParrot folder, and games that need you to pick the game file.
  - The graphics card warning also reads TeknoParrot's own game notes, so
    a game it says does not work on your AMD or Intel card is warned about
    even if TPM's list does not name it. The Intel warning names
    Golden Tee Live 2021 to 2026 and the PGA Tour games.
  - After a BepInEx install or update, the result tells you to start the
    game and close it twice the first time, and how to reset BepInEx.
  - If the DAT game list uses a format version TPM does not know,
    it says so in plain words and still reads it.
  - AutoSync gives each game its own folder and profile, even when its
    profile points at another game's folder or two games start with the
    same name (Daemon Bride, Daemon Bride - Additional Gain). Register
    Games repairs that profile after a saved copy. A failed unpack says why.

  Incredible Technologies games and PostgreSQL
  - Golden Tee Live and PGA Tour, PowerPutt Live, Silver Strike Bowling
    Live, Target Toss Pro and OCC Pinball: newer TeknoParrot profiles let
    you choose where the game keeps its database. Internal is the new
    default. It needs no database install; you start the game once so it
    makes its own database. Existing PostgreSQL keeps an existing server
    and its saved progress and works as before (PostgreSQL 8.3). For
    Internal games TPM skips every PostgreSQL check, install offer
    and "database missing" warning. It never switches a game from one
    choice to the other and never touches saved progress without a backup.
  - Every Incredible Technologies game with a database is covered: all
    Golden Tee Live years (2006 to 2023, 2025, 2026), all Golden Tee PGA
    Tour games (2021 to 2023, 2025, 2026), Power Putt Live, Silver Strike
    Bowling Live, Target Toss Pro and Orange County Choppers Pinball.
    TPM finds them by what their profile says, so a new game of this
    kind needs no new TPM version.
  - A game with TeknoParrot's "Automatically create Database" option and
    no starting database file is "Profile ready", not "left out":
    TeknoParrot makes the database the first time the game starts.
    Library health check says so instead of calling it a problem. A game
    that ships a backup is still restored from it.
  - Golden Tee Live 2021 to 2026 and the PGA Tour games share one game
    file name. A folder named after the game and year (for example
    "Golden Tee Live 2021") now registers to the right game.
  - Two games that name the same database (Golden Tee Live 2006 and
    Orange County Choppers Pinball use GameDB06) can be set up together.
    The first keeps the name; the other gets its own database made from
    its own backup, and its profile is saved with the new name. The old
    database is not changed and nothing is deleted. Library health check
    names games that still share one. If a game that shares the name has
    no starting file, setup stops before changing anything.
  - Golden Tee Live 2006: its backup holds data that is not valid UTF8
    (one table, category2_attr, came back empty). Such a backup is now
    restored into a database that keeps every byte.
  - Before the Windows permission window opens for PostgreSQL setup or
    repair, TPM waits for you to press Enter. Backups, database
    moves and saved proof files no longer stop on PCs with older-style
    folder permissions, and the log names the reason if one still fails.

  LaunchBox
  - One shared way to match games is used in the whole LaunchBox step.
    Games you add get their real name ("Too Spicy", not "2Spicy"), their
    release year and developer, and LaunchBox's official name and Games
    Database ID. A game is linked by itself only when the Eggman list,
    TeknoParrot and LaunchBox's game list agree, and a different year or
    number is never the same game. When it is not sure, you choose. Names
    you typed are never replaced. Firmware updaters, drive checkers and
    test boards are never added.
  - A game that cannot start yet (missing game file, missing firmware, or
    it needs BepInEx) gets a plain "Needs setup" note and goes into a
    "Needs setup" playlist. Both go away when the problem is fixed. What
    you wrote in the notes stays.
  - New choice V groups the regions and versions of one game into one
    LaunchBox game with a version picker, only when they are certainly
    the same game. The default follows your Region setup choice.
  - New choice S keeps LaunchBox in step with your library: games you
    removed are removed, moved folders get the new location, and old
    TeknoParrot Manager names become the clean title. A missing game file (an
    unplugged drive) never removes a game, and nothing is removed if most
    games would go at once.
  - Pictures from a folder are matched by the game itself when LaunchBox's
    game list is there: another name of the same game is a sure match, and
    a picture of a different game with the same name is never used.
  - New choice C fills in the players and controllers that Big Box shows
    (#267): how many players each TeknoParrot game has and which
    controller it needs (joystick, steering wheel, light gun, trackball
    or paddle), from the game's TeknoParrot controls. Empty boxes only:
    what you or LaunchBox already have is never changed. You see every
    game first and approve once. A saved copy is made first, the files
    are read back, and one question right after saving undoes it. Lights
    are not changed.
  - You see a preview first for all of these, and Restore undoes them.
    The platform TPM makes is called TeknoParrot and is scraped as
    Arcade, which is where LaunchBox keeps arcade games.
  - The LaunchBox offer screen is easier to read (one blank line was added).

  ReShade
  - New choice B in ReShade setup: use your own bezel folder. A bezel is
    a picture that frames the game, like a cabinet's edge. TPM
    matches your .png pictures to your games and shows how sure each match
    is. It copies nothing until you say yes, never uses an unsure match or
    a different sequel number unless you pick it, keeps a bezel you placed
    yourself unless you say to replace it, and saves a copy first. Undo
    puts everything back. Nothing is downloaded.
  - The bezel matcher was checked on a real folder of 177 bezel files and
    fixed: it reads the real game name from the TeknoParrot profile, not
    just its short code, matches short names like acedriv3 exactly (so
    daytona.png no longer goes to Daytona 3), treats Soul Calibur II and
    soulclb2 as the same number, and counts unused .jpg files (use .png).
  - Progress counts the games being changed ("Applying ReShade: 1 of 34"),
    not your whole library, and checking all your games is its own step.

  Updates and screens
  - The update check runs right after the program starts, before the "use
    saved settings?" question. The "Update Available" screen lists Y =
    Update now, N = Remind me later, V = View release notes.
  - You are never asked to approve the same thing twice. Update takes one
    Y. Restore all, restoring an old backup that cannot be checked, the
    LaunchBox restore and add, the Library Health path search, ReShade
    "Replace old files" and "Undo only the files that did not change", and
    the BepInEx install ask once. Every backup and undo is kept.
  - AutoSync no longer says "ACTION REQUIRED" when all your games were
    already extracted; skipping registration then is a short note.
  - The GPU fix at the end of first-time setup shows the same result as
    the menu. A game on a drive that is not connected is "skipped" and the
    drive letter is named; Library health check (menu 13) repairs paths.
  - The README and User Guide say the online list of TeknoParrot profiles
    is used only when it can be reached (it cannot yet: the repository is
    not public). Otherwise your own TeknoParrot profiles are used.
  - All screens and guides use American spelling.
  - The graphics card check is much faster and never goes silent.
  - The support package file name uses your PC's own clock.
  - "K = keep this layout, C = change one button" now has B to go back.
  - Patch Undo lists only the games that have something to undo.
  - Force feedback ends with what was set and the next step.

  v1.0 RC8.4 (changes since RC8.3)
  ----------------------------------------------------------------

  Fixes
  - Adding games with AutoSync no longer skips the second of two different
    games that have almost the same name, such as the Type X and
    NESiCAxLive versions of one game, or two versions of the same game.
    Each one now gets its own folder.
  - The BepInEx result no longer says "failed" when every game you picked
    worked.
  - If a game is on a drive that is not connected, installing or undoing a
    game patch gives one plain message about it.
  - ReShade tells you how many games it can change and that it leaves the
    others alone. A game it cannot check is no longer called unsafe or damaged.
  - The dgVoodoo2 scan line says how many games were checked and skipped.
  - Lists of games show the full game name, never a file name, and not "and 1 more".
  - The game picker shows how many games you have picked so far.
  - AutoSync now writes a line to the log for every ZIP it skips and says
    why, so a game that did not get unpacked can be traced.
  - The Propagate Controls result names every control family that has no
    game with your controls yet. It also lists games that are already set
    up and games skipped by your own rules on separate lines.
  - The game picker has an A choice for all games. Typed numbers like
    1,3,6 and 1-8 still work.
  - The result screens of patches, dgVoodoo2, BepInEx and the GPU fix say how
    many games you selected and how many were changed, already set up, skipped
    or failed, so the numbers add up. They also say where the backup is.
  - dgVoodoo2 names the result of every game you selected, with the
    reason for each skipped or failed game.
  - The Action Required list is grouped by feature, with a short heading
    for each group.
  - A step that skipped games on a drive that is not connected now points
    to Library health check (menu 13) to repair them.
  - Library health check lists the games that need BepInEx and do not
    have it set up.
  - A game file that cannot be read is now told apart from a game whose
    32-bit or 64-bit type could not be worked out.
  - A folder like "Time Crisis 5" is no longer registered as "Time Crisis 4".
  - The Propagate Controls preview no longer stops the real run from fixing the
    Input API, and "already set up" counts only games that have controls.

  Also new in this release
  - LEDBlinky lighting (optional): if you use LEDBlinky, TPM can add lighting
    info for your games. It looks for LEDBlinky on your drives and in Program
    Files, or asks where it is and remembers the folder. A game gets only the
    controls it uses that your cabinet has. You see a preview first, a saved
    copy is made, and you can undo it. Only entries TPM added are ever removed.
  - LaunchBox: TPM can look each game up in LaunchBox's own game
    list on your PC and use the official name and the Games Database ID,
    so LaunchBox can find info and artwork. Choose [L] in the LaunchBox
    step to do this for games that have no ID yet. You see every old
    name, new name and ID first and approve before anything is saved.
    Names you typed yourself are never replaced. Nothing is downloaded.
  - LaunchBox: "Fill in game details and make playlists" fills in the
    release year and developer where LaunchBox has nothing yet, and makes
    playlists for each arcade hardware family, plus "Light gun games" and
    "Driving games". Your own playlists and details are never touched.
    Restore puts everything back.
  - LaunchBox: a new optional step adds clear logos or box art from a
    folder you pick. You see a preview first, close matches are used only
    if you say yes, and Undo removes the pictures that were added.
  - Games that need PlayStation 3 firmware (RPCS3) or a Play! game file are now

  v1.0 RC8.1 (changes since RC7)
  ----------------------------------------------------------------

  Updates
  - Check for Updates installs the whole release (scripts, data and tools),
    not only the main script. It downloads the update and checks it with
    SHA-256, looks inside the ZIP first, backs up every file it replaces,
    installs it and checks it. If anything goes wrong, every file is put
    back. It says so when there is not enough free space. Your own files
    and older files the release no longer has are never deleted. Then you
    start TeknoParrot Manager again yourself.
  - If an update was cut off (power loss or a closed window), the next
    start says so and tells you how to get the old files back from the
    UpdateBackups folder. It never deletes anything for you.
  - Older builds cannot do this. Install RC8.1 or newer by hand once: download
    the ZIP from the Releases page and extract it over your old folder.
  - A ZIP without the script, or a CPS3 ZIP that cannot be read, is
    refused. If the Eggman page has no DAT file, it says so.
  - The updater says the old version was put back only when it checked that
    it was. Sync-And-Run says so when it could not check for updates. The
    update check works from another folder with a relative script path.

  Screens and messages
  - The first question asks for your TeknoParrot folder. Type it, press B
    to browse or press Q to quit. Closing the browse window without
    choosing asks the question again. A folder without TeknoParrotUi.exe is
    explained in plain words and asked again.
  - When TeknoParrot's own first-time setup is not finished, the Action
    Required list says so once, with the path to TeknoParrotUi.exe and the
    steps left: choose the DAT file, scan for games, set up controls.
  - Result screens are short and use plain words. File names, folders and
    codes are under Details (press D) and in the log.
  - Progress bars look like bars, change color as they fill, show finished
    counts and no longer wrap in a narrow window. A long quiet wait says
    "still working". A step that failed ends red.
  - The console is not resized inside Windows Terminal. Start-up does not
    wait for a key press about your custom rules. Q closes the program. The
    main menu works in a very short window.
  - Saying N to "Tidy up now?" leaves your settings as they were and does
    not block the next start. An older report beside the script is left
    where it is when a newer one exists.
  - The guides were rewritten for a first-time user and match the real
    screens. The two launcher files (.bat) say where the log file is. All
    screens, guides and notes use American English spelling.
  - Folder prompts accept a path pasted with quotes and a whole drive such as
    D:\. Canceling the staging-folder picker asks again. Back in Reset and
    Restore returns to its menu.

  Testing
  - A new read-only validation report (-ValidationReport) checks a copy
    and one TeknoParrot folder without any questions. It shows the version,
    your games, which games still need PostgreSQL settings, how many
    profiles support RawInput or RawInputTrackball, and any warnings. It
    changes nothing and can save the result as one JSON file you name. See
    the README for the exit codes.
  - After you register a game that needs PostgreSQL, TeknoParrot Manager
    asks once if you want to set it up now. Saying no changes nothing.

  Games and folders
  - Registering now finds PCSX2x6 games: their .acgame files were never
    looked at before, so those games did not register by name.
  - Library Health Check has a Game support row. It says when a game
    needs you (game file missing, second game file not chosen, PostgreSQL
    settings missing). Details show the counts for each emulator.
  - AutoSync no longer stops when all your game ZIPs together are bigger
    than your free space. It tells you that is OK, and you pick only some
    games. Run it again later for the rest. Space is still checked before
    each game, and a game that does not fit is skipped with nothing changed.
  - AutoSync says when it skips a .7z or .rar archive (it only unpacks
    .zip files) and tells you to unpack it yourself, then use Register only.
  - AutoSync leaves a game folder alone when its ZIP did not change, so
    saves and settings you made are not replaced. When a changed ZIP does
    replace a folder, every file in it that is extra or different from the
    ZIP is first copied to Backups\AutoSyncReplaced. If those files cannot
    be saved, or no Backups folder is set up, that game is not updated and

  - AutoSync only extracts the ZIPs named in onlySync. The ZIP picker lists
    and extracts a game once when both source folders hold it.
  - A familyOverride in the overrides file also applies to the games
    controls are copied from, so a game set to "spinner" finds a reference
    game instead of "no usable reference game".
  - Games in very long folder paths (over 259 characters) are found, read
    and configured everywhere. Installing add-ons into one says the path is
    too long and changes nothing.
  - A game whose 32-bit or 64-bit type cannot be read is not counted as
    ready, and force feedback does not give it a 64-bit plugin.
  - ReShade works with both 32-bit and 64-bit games. Games that run through
    BudgieLoader (a Linux-style game format) are skipped for now. ReShade does
    not show its welcome window, counters or messages when a game starts.
  - Registering games and repairing paths keep a second executable path that
    points at a file that exists. A manual path repair checks its safety
    copy first and leaves a profile TeknoParrot changed meanwhile alone.
    If saving a profile fails after Windows removed the old file, the new
    file is kept and the message says where it is.
  - Region setup (main menu item 10) sets the region of your games. After
    new games are registered you are also asked once which region to use.
    Only regions the games really offer are listed. A game never gets a
    region it does not have, and a region you chose before is kept unless
    you change it in Region setup. You can pick all games or some, and go
    back to the automatic region. A restore point is saved first.
  - Missing startup files (firmware for PCSX2x6 games, four files for
    Chihiro games, PlayStation 3 firmware for RPCS3 games) are found before
    you start, and the screen says which games will not start. Files from
    your own collection are copied after a check against the Eggman DAT
    list; the PlayStation 3 firmware is installed from the firmware file in
    your collection. Nothing is downloaded or supplied. Optional CPS3
    first-boot files are copied only when the whole set matches. Play!
    games are checked for their own settings file.
  - Required game patches can be up to 512 MB, can be 7z or RAR files when
    7-Zip is installed, and work on long paths. Free space is checked first.
    You are asked only for the ZIP of the game version you have. AMD and
    NVIDIA patches work with an extra Windows display adapter. With two real
    graphics cards you are asked once which one the game uses. Undo works
    with a trailing backslash and ignores the version you never installed.
  - Game notes (what each game needs: firmware, BepInEx, administrator,
    setup program) and the LaunchBox import file are saved in the Reports
    folder. If notes cannot be saved, you are told.
  - A saved DAT list is kept when an old DAT path is left in the overrides
    file. A DAT file set only there is used and the start-up question is
    skipped. Canceling the DAT save window downloads nothing. Two ZIP
    folders, one inside the other, do not block the DAT download.
  - With two TeknoParrot folders on one PC, your settings are found and the
    "copy from another TeknoParrot folder" step finds both.

  ReShade, dgVoodoo2, force feedback and crosshairs
  - ReShade has 25 approved effects and 17 profiles for arcade play: Original,
    11 CRT looks and 5 other looks. Each has a short description and a rough
    light, medium or heavy cost. The preview shows approximations. Its
    drop-down follows the numbered list, and a choice is only used when you
    confirm it.
  - You can change the ReShade look at any time and undo it for one game or

    whether to keep it (the default) or turn it off for that game.
  - The ReShade result names each game that is left alone, and why, under
    Details. A game with only a leftover ReShade.ini can be replaced; the

    undo copy could not be finished.
  - dgVoodoo2 copies the dgVoodoo.conf from your dgVoodoo2 folder to each
    game that has none. A game's own file stays, and a per-game preset wins.
  - Force feedback setup keeps a plugin it just installed and updates one
    you installed earlier through TeknoParrot Manager. A file that is not
    ours is never overwritten.
  - Crosshairs for ElfLdr2 go only into the real loader folder. Every
    skipped game is named with the reason, and a skipped game does not make
    a finished setup say "was not completed". The PCSX2 first-run question is
    asked once. The force feedback count never goes over the number of games.
  - When GitHub answers but a download is missing, the screens say that and
    do not blame your internet.

  PostgreSQL setup and restore
  - When setup stops, it says what happened to your data: put back and
    checked, or could not be checked. After a repair that stopped part way
    it says some things may have changed and points to View Log. A failed
    install says whether the Windows installer had already run. A rollback
    removes only a database made in that run.
  - Password prompts can be left by pressing Enter.
  - Setup keeps a note about databases it is building. If the PC stops in
    the middle, the next setup removes only the half-built database and
    builds it again.
  - Every game database is made ready during setup and tested with the
    game's own settings: it must connect and hold its tables. Nothing is
    left for TeknoParrot to create when you first start a game. A game
    with no starting database file (pg_backup) cannot be made ready: it
    is left out and named, and every other game is still set up.
  - A game with several identical backup files gets its database from the
    newest one, in setup and in the [I] rebuild. The confirm screen, Details
    and the log say which file was used. If it does not restore, setup stops
    and puts everything back. A backup with no ".backup" ending works, and
    notes such as readme.txt are never used as a backup.
  - A backup that is cut short is never offered for restore. Five known
    warnings at the end of a game backup do not undo setup; Details name
    the links between tables that could not be made.
  - Setup names each game profile that needs a fix and never writes over a
    profile saved while it ran. It asks before touching a game that points
    at another server, port or user. Choosing K leaves that profile alone.
  - Before the Windows permission box, you are told to approve it with an
    administrator account of this PC. If it fails twice, "Try again" stops
    and says why.
  - PostgreSQL tools have time limits, so a stuck tool counts as failed. A
    short password such as "1" works. A failed check does not reset the
    password. Capital letters in database names work.
  - Two TeknoParrot Manager windows cannot change PostgreSQL at once, and a
    database made by another window is not removed. A database just created
    is not counted as "Already set up".
  - A restore keeps the database's text encoding when it is known. A backup
    that is only locked says "could not be read, try again".

  Backups and undo
  - Restore points are made at start-up. A Reset and Restore menu keeps
    working after TeknoParrot is moved, and Restore all brings back
    TeknoParrot Manager's own settings, even after the tidy-up moved them.
  - Restore backup has a new choice, Rebuild one game from its ZIP. It puts
    a broken game folder back to exactly what its ZIP holds. The ZIP is
    unpacked and checked first (and checked against the DAT list when the
    game is in it). Your old folder is not deleted: it is kept aside, and
    you can put it back or delete it from the same menu.
  - LaunchBox: games can be added directly. It asks first, waits for
    LaunchBox to close (it never closes it) and saves a checked copy of each
    file before writing. Restore lists UserProfiles, Postgres and LaunchBox
    backups, and a backup from another folder needs its own confirmation.
    Restore backup does not list the copies made when ReShade is removed.
  - PostgreSQL recovery files are private to your Windows account. Older
    recovery folders move into TeknoParrotManager\Backups.
  - BepInEx installs and updates keep a verified backup and roll back only
    what TeknoParrot Manager made. An update that could not remove its
    temporary files is shown as finished, with a note. A finished game mod
    update leaves no spare copy in the game folder.
  - If the registration record cannot be read, the file is left as it is and
    you are told. AutoSync only calls its profile backup complete when it
    matches your live profiles. A short registration list is saved in its own
    file, and ACTION REQUIRED does not say a list was saved when none was.

  Library Health check
  - It says "Could not check" and asks for attention, instead of OK, when
    it could not read the PostgreSQL service, the game profiles, the startup
    files or a game, or did not look at an area. Games on a drive that is not
    connected tell you to reconnect it. A game in a very long path counts as
    not fully checked.
  - A damaged game profile is named as "could not be read" and gets no path
    repair. It does not stop the LaunchBox preview or add for other games.
    A path with characters Windows does not allow is named "not a valid
    path". Paths with spaces around them are read correctly.
  - Choosing ReShade in the check starts ReShade setup.

  Support package
  - Create Support Package makes one cleaned ZIP with logs, Windows errors,
    PC facts and full game names. No game programs, crash dumps or passwords.
  - A package with missing information says "partial" and names what is
    missing. An empty log file is not called a failure. It keeps the newest
    part of a main log over 5 MB, lists each game's real controls and counts a
    profile snapshot only if it is inside. A complete ZIP that left a temporary
    folder behind says it is ready to send and names the folder under Details.
  - The package now says how the last finished job ended, such as a
    setup that stopped, even after you restarted. It keeps the last few
    step results with personal folder names removed.

  Other
  - Missing startup files are not listed under ACTION REQUIRED after they
    were copied. The run recap counts a DAT list you picked at start-up.
  - If the only thing left is a game type that has no example game for
    copying controls, the next step is still shown and saved.
  - Game folders that match no TeknoParrot profile are now described
    more carefully: the main file may just have a different name.
  - Release packages hold only the files users need. On a slow PC, a late
    drive check does not show a wrong "could not tell" warning.
  - The game notes file now also lists the guide's setup steps, graphics card
    notes and extra files for your registered games, not only the free-text
    notes. It also names the extra archives a game needs (you bring your own
    copy; none is downloaded), a linked profile, and a game the guide lists as
    broken or only partly working. Nothing in it is applied for you.
  - The graphics card warning list has five more games that do not work
    on an Intel graphics card.
