===============================================================================
  TeknoParrot Manager  --  CHANGELOG
  Author: Jumpstile
===============================================================================
  Newest version first. RC9.5 is in progress. RC9.4 is the latest published version. RC9.3 is the
  previous published version. RC9.2 came before it. RC8 was a tester build and
  was never published. Final Version 1.0 comes later.

  TeknoParrot Manager is for beginners and is also useful if you already know
  TeknoParrot. It hides complexity, not detail: repeatable bulk steps, previews,
  backups before changes, a log of what was done. See docs\ADVANCED-USERS.md.

  v1.0 RC9.5 (changes since RC9.4)
  ----------------------------------------------------------------
  - Controller layout, choice 5 (My learned arcade controls): before you
    are asked to keep or change it, TPM now shows the keys it saved, grouped
    as Player 1, Player 2 (and 3 or 4 if used), menu and admin controls, and
    the trackball. A game's own DirectInput button now shows its button or
    axis number and device when the game file names them.
  - Learn my arcade buttons can now learn a trackball (left and right, up and
    down) by watching the pointer move, then asks which device is your
    trackball (TPM reads it from the Windows Raw Input device list). For
    games whose own file has a single trackball control, it shows which games
    will get your trackball and, only after you say Y, writes the trackball
    device into that one control. A saved copy of your game settings is made
    first, the file is read back, and Undo puts it back. A trackball that is
    already set is kept unless you say to replace it, and a game whose file
    looks different is left alone and listed to set up by hand. If TPM cannot
    read the device, it writes nothing. It does not switch anything to
    XInput. Not verified with a real trackball.


  - First-run setup now searches every local drive for TeknoParrot (the
    drive root, the folders in it, and the usual game and emulator folders),
    not only a few fixed folders. It shows each install it finds with its
    drive letter, full path and version, says which drives it searched, and
    lets you pick one, search again, browse, or quit. Nothing is changed
    until you choose.

  - ReShade setup: the result now shows the first check (ready and left
    out) and the last check before installing separately. Every game that
    was ready but skipped at the last check is named with a plain reason,
    and the protected count says how many were found at each check. A game
    whose program type could not be read is no longer described as 32-bit
    in the advice.

  - Game path repair no longer offers another edition or version of a
    game just because its game file has the same name (for example Tekken 7:
    Fated Retribution 1.06.00 and the Round 2 4.20 folder). A game whose
    old folder name only lacks a version or [TP] tag is found again.
  - Games that could not be matched to a folder are listed with their full
    name, version and year, with the choices Fix, Remove, Skip, Ignore and
    Details for one game, several or all. Remove makes a backup first and
    never deletes game files. Ignore is saved until you turn it back on.
  - After registration and repair, ReShade, GPU Compatibility Fix,
    dgVoodoo2 and the controller steps use one list of ready games, so a
    game that is unresolved, on a drive that is not connected or ignored is
    named once instead of warned about in every step.

  - Required patches: Dragon Dance now has a patch for its newer
    iDmacDrv32.dll, read from the RAR inside "Dragon Dance.rar" (7-Zip must
    be installed; a RAR inside a RAR now works). It saves a copy and can be
    undone. Block King's patch is listed as "not ready yet".

  - Required patches: TeknoParrot Manager can now copy a whole folder of
    patch files into a game (or into your TeknoParrot folder), all files
    together or none, with a saved copy of every file it replaces and one
    Undo. It never downloads the files. The House of the Dead EX and Tatsunoko
    vs. Capcom use it, but stay "not ready yet" until the real files are
    measured.

  - Library health repair (R) now points a game only at the same game and
    version. It no longer picks a different version's folder just because
    it holds a file with the same name and path. Games that are not on the
    drive, or whose game file is missing from the right folder, are listed
    with a plain reason and left unchanged. A game file one folder deeper
    (for example game.bin) is now found.
  - When a game could not be registered, the result now counts it, names it
    and says what to do next (close TeknoParrotUI, run Register Games
    again). The saved ACTION REQUIRED list names these games too, and the
    log's "Completed" line ends with Failed=<number>.
  - If AutoSync unpacked nothing because ZIP files failed, it says so and
    points to View Log, instead of saying nothing new was extracted.
  - The outside controller list check holds a game back when a label in the
    list names a different control (for example Start on a Coin control) or
    when the game file changed since you last checked the same list.
    -MappingEvidenceCommit saves which version of the list you checked.
  - Required patches: when a game has several patch versions and nothing on
    your PC tells them apart, the menu asks you to pick one (Back cancels).
    The Fast and the Furious: Drift (screen size) and Chase H.Q. 2 (region)
    can now be installed. Only the version you pick is installed, with the
    usual exact-file check, backup, receipt and undo.
  - Ghost Squad Evolution: the AMD or Nvidia shader fix can now be installed.
  - The note about TeknoParrot's own first-time setup says "TeknoParrot
    Manager" in full.
  - Any error you could see on the screen during a run is also written to
    the TeknoParrot Manager log, so it is in the support package too.
  - Health Check no longer stops on a game that uses Internal storage.
  - Learn my arcade buttons: a control you skip loses its old saved key when
    you save.
  - dgVoodoo2 names the drives that are not connected and points you to
    Library health check. A game that already had every file is named, and
    the screen says its files were kept, not checked. The ReShade result
    screen says "Press Enter to continue to dgVoodoo2".
  - TeknoChi games (the new SEGA Chihiro profiles) are no longer reported as
    an unknown game type in Library health check. TeknoParrot has not
    released them yet, so they show as "not available yet".
  - The status line at the bottom of a screen repaints in place instead of
    erasing and redrawing, and when a console cannot pin it, all of its
    lines (including what happened to your files) are shown, not only the
    first.
  - Before it registers games, TeknoParrot Manager waits up to 30 seconds
    for TeknoParrot to make its first game profile. If none appears, it
    says to open TeknoParrot once and run again.
  - If PostgreSQL recovery stops, the screen and the log now say which part
    stopped: RecoveryPolicyApply (putting the PostgreSQL login settings file
    back) or RecoveryServiceStart (starting PostgreSQL again), and what to
    do next.
  - Library health check: TeknoChi games now need the same Chihiro startup
    files as the older Chihiro games, and it names the missing ones.
  - If TeknoParrot has game profiles for a newer emulator (TeknoZR107) but
    that emulator is not on your PC, Library health check says TeknoParrot
    needs an update. Update TeknoParrot, then run the health check again.

  - Game Path Repair now uses the folder names and file name of a game's old

  - When TeknoParrot has been updated, TeknoParrot Manager now tells you at

  - Game rules (game notes and graphics-card warnings) can now be updated
    without a new TeknoParrot Manager release. The update is a small signed
    data file. It never changes your game or TeknoParrot files, and you can
    turn it off with the GameRulesUpdate setting in
    TeknoParrot-Manager.config.json. You are told once.
  - A recovery file already gone, in a folder with square brackets in its
    name, is now correctly seen as missing on Windows PowerShell 5.1.
  - The ReShade preview window now stays inside the screen, and the ReShade
    list names all four groups again.
  - ReShade setup: pressing B at the first one-by-one question goes back to
    the previous menu instead of canceling. The install line counts only the
    games really being changed. The profile question says nothing changes
    until you choose games; the apply question says it changes game folders.
  - ReShade setup: when a game already uses TeknoParrot's CRT look, the
    notice says that look stays on, ReShade adds another effect, and names
    the game. A game whose 32-bit or 64-bit type cannot be read is left
    unchanged, with a plain note that it is not damaged.
  - The ReShade guides now say 32-bit and 64-bit games both work, and list
    ReShade32.dll next to ReShade64.dll.
  - ReShade setup for many games now ends with a short summary and groups
    skipped games by reason. It no longer warns about a failure when every
    game that could be set up was set up. Press D for the game lists.
  - dgVoodoo2 setup: the scan line shows how many games were checked out of
    the total, and explains that kept DLL files are not checked or replaced
    and that dgVoodoo.conf comes from your dgVoodoo2 folder.
  - dgVoodoo2 setup: one summary now names how many games were checked,
    need it, were set up, were already set up or were skipped, with [D]
    Details for each game, also when nothing needed changing.
  - In the game list, a game's second profile uses the second executable
    named in the list when the profile names no game file.
  - Forgot your PostgreSQL password: a short explanation of why it cannot be
    reset automatically, then 8 numbered steps to reset it yourself, ending
    with turning the safety check back on. The Action Required list and the
    validation report point to those steps and save them. There is also a
    new User Guide appendix and matching Troubleshooting and Postgres Setup
    wiki sections.
  - TeknoParrot Manager no longer looks up a game list online. It reads the
    profiles in your own TeknoParrot GameProfiles folder.
  - The license file and a few notes now use American English.
  - Required game patches: the APM3 patches for several ALLS games (such as
    Otoshu DX, Dead or Alive 6 and Rolling Gunner) now also accept the
    game's own ZIP. When a patch ZIP is not found, the screen names the
    exact files that would work and says TeknoParrot Manager does not
    download them.
  - A settings file that cannot be read is now left as it is and not saved
    over. TeknoParrot Manager tells you how to fix it or rename it.
  - Undo for a bezel now puts your own saved bezel back even when the copy
    TeknoParrot Manager made was already deleted. The one-time game rules
    notice is shown only when the update can really run, and a game rules
    update that fails halfway keeps the rules you had.
  - The guides no longer tell you to delete a dgVoodoo.conf you may have
    edited without copying it first. They also say that the PostgreSQL
    "start any game" line appears only when every game is ready, and that
    B does not cancel at the first ReShade menu.
  - The guides now say a Preview still reads your files and writes the log,
    that recovery copies are not private on FAT drives, and that LaunchBox
    must be closed before a restore.

  - Several screens now say only what is true: Undo for a rebuilt game, the
    LaunchBox preview and results, the PostgreSQL results, the force
    feedback and BepInEx results, and the library health check, which no
    longer says everything is fine when a check could not run.
  - Graphics-card warnings now appear for AMD and Intel players. They were
    missing, and a red error line showed instead.
  - Learn my arcade buttons now keeps the keys you saved before and asks only
    for the controls that have none.
  - ReShade setup: typing a look's number now shows a short line, not the
    whole list, and U goes on to choosing games (no second question).
  - The saved game files offer now says "TeknoS11 arcade games" and lists all
    its boards equally (System 10, System 11, System 12, Sony ZN, Konami 573, Taito G-NET).
  - AutoSync no longer skips a game just because another edition of the

  - The TeknoParrot Manager log no longer grows without limit. At start,

  - Screens, lists and reports now show each game's full title (for example
    "Tekken 2"), not its profile code, in Controls too. Code stays in log.
  v1.0 RC9.3 (changes since RC9.2)
  ----------------------------------------------------------------

  - TeknoParrot Manager is made for beginners and is also useful if you
    already know TeknoParrot: repeatable bulk steps, previews, backups
    before changes, and a read-only validation report. Details stay one
    step away (see docs\ADVANCED-USERS.md).
  - The guides now explain why a game can work from TeknoParrot but not
    from RetroBat, and who does what. They also give the right bezel undo
    path (6, B, U).
  - AutoSync no longer takes a game's ZIP as already unpacked when the folder
    it found belongs to a different game with a similar name. Each ZIP gets
    its own folder, and a saved record that names another game's folder is
    ignored. Repair says when it cannot tell game paths apart.
  - Unpacking a game shows progress by size, and Ctrl+C shows "canceled"
    instead of "failed". If the games folder you chose cannot be used, Q goes
    back to the menu, and a closed browse window asks again.
  - The PostgreSQL offer after adding games says how many other games still
    need it. In a preview it names them without asking for anything secret.
    Setup screens now name Golden Tee Live 2020. If PostgreSQL cannot be put
    back after a stopped setup, the screen says what happened to your
    databases and that the service is the open problem.
  - The Capcom CPS3 first-boot files step lists your CPS3 games and stops
    without changes while a CPS3 game is running.
  - Before you confirm Copy Controls, each control type shows which example
    games it is copied from, and games with no example are listed as still
    needing controls.
  - BepInEx setup shows your list before installing: new installs and
    updates apart, each with a reason, and you can take games off. Library
    health check counts BepInEx games as installed, missing, not supported
    or not checked.

  v1.0 RC9 (changes since RC8.4)
  ----------------------------------------------------------------

  Controls
  - Controller layout (Propagate Controls, menu 3): choose your layout once
    (Xbox, PlayStation, Nintendo or arcade stick), change any button, then set
    up one game, all your games, or game by game. You see a preview and approve
    once. A saved copy is made first, every changed game is read back, a game
    that does not read back correctly is put back exactly, and one step undoes
    the whole run. A game is left alone, with a plain reason, when its saved
    settings are for another version, a control is missing, or an Xbox button
    is already used. Triggers and analog sticks are never set. Test and Service
    stay empty unless you give them a button.
  - Controls check (Propagate Controls choice 4, and a Controls line in Library
    health check) sorts every registered game into every control set up, some,
    none, or "cannot tell", and names the missing controls. For most games the
    list comes from TeknoParrot's own game file and says that no person has
    checked it. It changes nothing and never says a game is ready.
  - The Device Survey saves your answers in TPM's own settings
    folder and asks one question next time: "Keep these answers?" It asks
    again only if a controller turns up that you said you do not have. A
    damaged answers file is set aside, never overwritten.
  - "My controls" (choice 5) learns your arcade buttons: press each control and
    TPM remembers the key it sends. If LEDBlinky is installed it offers its key
    list first. Before it learns, it checks for a stuck button (2 seconds,
    hands off) and tells you if a press also sends another key or a button
    stays down after 3 seconds. It offers the standard keys that MAME and
    Ultimarc I-PAC boards use only after you say yes and two buttons you press
    send those keys. Nothing in your game files changes.
  - TPM tells you when you changed your arcade encoder. It keeps a private
    one-way code for each Ultimarc-type encoder (maker and model numbers are
    never saved, logged or shared) and says whether it is the same encoder, one
    was added or removed, or it could not check. It is a hint only and never
    changes a saved key or answer. A different USB port is not a change.
  - You can show or print the controls of one game, and your cabinet's
    controls, as a page with pictures: each control, your key, and whether
    the game has it set up. It suggests your key only for coin, start,
    numbered buttons and plain directions, and says "I'm not sure" for the
    rest. If your own LEDBlinky file gives a control a color, it shows.
  - The page for one game now says if your cabinet has enough players
    and buttons, and which device the game needs (trackball, spinner,
    wheel and pedals, light gun) that you said you do not have, with
    what can stand in (an Xbox controller to steer, a trackball or the
    Xbox stick to aim). It says "not known" when you never told
    TPM. It only compares and changes nothing.
  - Learning buttons asks if your cabinet has an Exit, Pause or Menu
    button (Esc counts as a key for these). My controls offers "6 = Undo
    my last save" when an older copy of your answers exists: it shows
    what comes back, asks once, and keeps your newest answers as a copy.
  - You can tell TPM that a game played well. It keeps that with the date and
    the game's revision, and calls the controls Verified until they or the
    settings change. Starting a game never makes it Verified. Wheel, gun and
    other analog games need you to say the calibration is done first. A
    first-run Test or Service menu step can be marked as still to do.
  - When Propagate Controls skips games because no game of their type has
    your controls yet, it names one game of each type to set up first in
    TeknoParrotUI and says that choosing a device does not set up a game.
    The registration screen ends with "Registration run finished", which
    does not mean every game's controls are set up.
  - The Propagate Controls screen no longer says "No game is registered
    or extracted.", which read as if nothing was registered on your PC. It
    now says that the screen never registers or unpacks games.
  - A read-only check of an outside controller list (for example RetroBat's
    teknoparrot.yml), run from the command line with -MappingEvidenceFile and
    -ValidationRoot. It prints plain counts, trusts nothing and changes no
    profile. It holds back a game, and says why, when the list names it twice,
    sets a control twice or one the game does not have, uses an unknown button
    name, or puts two game actions on one button.

  Games and registration
  - Every game in the Eggman list was run through the real registration on a
    fake collection (1,596 games) and the gaps are fixed. A game gets the
    profile the list names for it, not the one with the most alike name (The
    King of Fighters XII was registered as XIV). A second version of a game is
    registered, or reported as a duplicate when TeknoParrot has one profile for
    both. A second profile the list names is registered when TeknoParrot
    retired the first (the ElfLdr2 profile next to each Lindbergh game). Files
    ending in .exec or .chd and names with a hyphen (R-Tuned) are recognized. A
    folder for a game TeknoParrot has no profile for (Sega Rally 3 track mods)
    is listed as "not in TeknoParrot", not as a failed profile.
  - A game set is never registered just because its parent ZIP is in the
    folder, except when the Eggman list names the parent ZIP (17 games,
    such as Dance Dance Revolution 2nd Mix Link). TeknoS11 arcade games need
    both ZIPs in one folder. The disc image (CHD) is chosen when there is
    only one, never guessed when there are several. If you have your own
    saved files set, TPM can copy the files for your games. It never
    replaces a file that is there and says which games the set lacks.
  - Startup files for Chihiro, PlayStation 3 and the other systems that
    need them now work like the CPS3 step. If TPM cannot find
    them, it asks once for your Supplementary folder and remembers it.
    One Y installs everything. The result names what was installed,
    already matching, missing (by file name) or invalid, and the folders
    searched.
  - Library health check names game types it does not know, games
    TeknoParrot has not released yet, emulators missing from your
    TeknoParrot folder, and games that need you to pick the game file.
  - The graphics card warning also reads TeknoParrot's own game notes, so
    a game it says does not work on your AMD or Intel card is warned about
    even if TPM's list does not name it. The Intel warning names
    Golden Tee Live 2021 to 2026 and the PGA Tour games.
  - After a BepInEx install or update, the result tells you to start the
    game and close it twice the first time, and how to reset BepInEx.
  - If the DAT game list uses a format version TPM does not know,
    it says so in plain words and still reads it.
  - AutoSync gives each game its own folder and profile, even when its
    profile points at another game's folder or two games start with the
    same name (Daemon Bride, Daemon Bride - Additional Gain). Register
    Games repairs that profile after a saved copy. A failed unpack says why.

  Incredible Technologies games and PostgreSQL
  - Golden Tee Live and PGA Tour, PowerPutt Live, Silver Strike Bowling
    Live, Target Toss Pro and OCC Pinball: newer TeknoParrot profiles let
    you choose where the game keeps its database. Internal is the new
    default. It needs no database install; you start the game once so it
    makes its own database. Existing PostgreSQL keeps an existing server
    and its saved progress and works as before (PostgreSQL 8.3). For
    Internal games TPM skips every PostgreSQL check, install offer
    and "database missing" warning. It never switches a game from one
    choice to the other and never touches saved progress without a backup.
  - Every Incredible Technologies game with a database is covered: all
    Golden Tee Live years (2006 to 2023, 2025, 2026), all Golden Tee PGA
    Tour games (2021 to 2023, 2025, 2026), Power Putt Live, Silver Strike
    Bowling Live, Target Toss Pro and Orange County Choppers Pinball.
    TPM finds them by what their profile says, so a new game of this
    kind needs no new TPM version.
  - A game with TeknoParrot's "Automatically create Database" option and
    no starting database file is "Profile ready", not "left out":
    TeknoParrot makes the database the first time the game starts.
    Library health check says so instead of calling it a problem. A game
    that ships a backup is still restored from it.
  - Golden Tee Live 2021 to 2026 and the PGA Tour games share one game
    file name. A folder named after the game and year (for example
    "Golden Tee Live 2021") now registers to the right game.
  - Two games that name the same database (Golden Tee Live 2006 and
    Orange County Choppers Pinball use GameDB06) can be set up together.
    The first keeps the name; the other gets its own database made from
    its own backup, and its profile is saved with the new name. The old
    database is not changed and nothing is deleted. Library health check
    names games that still share one. If a game that shares the name has
    no starting file, setup stops before changing anything.
  - Golden Tee Live 2006: its backup holds data that is not valid UTF8
    (one table, category2_attr, came back empty). Such a backup is now
    restored into a database that keeps every byte.
  - Before the Windows permission window opens for PostgreSQL setup or
    repair, TPM waits for you to press Enter. Backups, database
    moves and saved proof files no longer stop on PCs with older-style
    folder permissions, and the log names the reason if one still fails.

  LaunchBox
  - One shared way to match games is used in the whole LaunchBox step.
    Games you add get their real name ("Too Spicy", not "2Spicy"), their
    release year and developer, and LaunchBox's official name and Games
    Database ID. A game is linked by itself only when the Eggman list,
    TeknoParrot and LaunchBox's game list agree, and a different year or
    number is never the same game. When it is not sure, you choose. Names
    you typed are never replaced. Firmware updaters, drive checkers and
    test boards are never added.
  - A game that cannot start yet (missing game file, missing firmware, or
    it needs BepInEx) gets a plain "Needs setup" note and goes into a
    "Needs setup" playlist. Both go away when the problem is fixed. What
    you wrote in the notes stays.
  - New choice V groups the regions and versions of one game into one
    LaunchBox game with a version picker, only when they are certainly
    the same game. The default follows your Region setup choice.
  - New choice S keeps LaunchBox in step with your library: games you
    removed are removed, moved folders get the new location, and old
    TeknoParrot Manager names become the clean title. A missing game file (an
    unplugged drive) never removes a game, and nothing is removed if most
    games would go at once.
  - Pictures from a folder are matched by the game itself when LaunchBox's
